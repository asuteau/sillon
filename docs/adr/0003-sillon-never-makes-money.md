# Sillon never makes money

Sillon is a public app that any Discogs user can sign in to, and it is free with no exceptions: no ads, donations, paid tier or affiliate links, and nothing else that brings in money or other consideration. Both licences it depends on require this. Deezer's API terms allow only non-commercial use, with no revenue of any kind, and Discogs forbids commercial use of Restricted Data (collection, wantlist, user profile, marketplace data).

## Consequences

- Introducing any income means dropping Deezer Covers (every record would get a House sleeve) and asking Discogs for written permission.
- Outbound links to other shops (roadmap "Find elsewhere") can never carry affiliate tags.
